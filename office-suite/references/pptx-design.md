# Design Guidance

This guide applies when **creating from scratch** or when the template gives you design freedom. If you're editing an existing deck, **preserve the deck's visual language** — don't introduce a new style.

---

## Before You Start

**Pick a bold, content-informed color palette.** If swapping your colors into a completely different presentation would still "work," the choices aren't specific enough.

- **Dominance rule**: one color should own 60–70% of visual weight; 1–2 supporting tones; one sharp accent. Never give all colors equal weight.
- **Dark/light contrast**: dark backgrounds for title + conclusion slides, light for content ("sandwich" structure) — or commit fully to dark throughout for a premium feel.
- **Visual motif**: pick ONE recurring element and apply it consistently across every slide (rounded image frames, icons in colored circles, thick single-side borders, etc.)

Choose a pairing with personality — don't default to Arial.

|---------|------|
| Slide title | 36–44pt bold |
| Section header | 20–24pt bold |
| Body text | 14–16pt |
| Captions | 10–12pt muted |

## Per-Slide Layout

**Every slide needs a visual element** — image, chart, icon, or shape. Text-only slides are forgettable.

Layout options to rotate through:
- **Two-column**: text left, illustration right
- **Icon + text rows**: icon in colored circle, bold header, description below
- **Grid**: 2×2 or 2×3 content blocks, possibly with a half-bleed image on one side
- **Half-bleed image**: full left or right side with content overlay
- **Stat callouts**: large numbers (60–72pt) with small labels below
- **Comparison columns**: before/after, pros/cons, side-by-side options
- **Timeline/flow**: numbered steps with arrows

---

## Spacing

- 0.5" minimum margins from slide edges
- 0.3–0.5" between content blocks
- Leave breathing room — don't fill every inch

---

## Avoid (Common Mistakes)

- **Don't repeat the same layout** — actively vary across slides
- **Don't center body text** — left-align paragraphs and lists; center only titles
- **Don't skimp on size contrast** — titles need 36pt+ to stand out from 14–16pt body
- **Don't default to blue** — pick colors that fit the specific topic
- **Don't mix spacing randomly** — choose 0.3" or 0.5" and use consistently
- **Don't style one slide and leave the rest plain** — commit fully or keep it simple throughout
- **Don't create text-only slides** — always add a visual element
- **Don't forget text box padding** — set `margin: 0` when aligning text with shapes at the same x-position
- **Don't use low-contrast elements** — icons AND text need strong contrast against the background
- **NEVER use accent lines under titles** — hallmark of AI-generated slides; use whitespace or background color instead
